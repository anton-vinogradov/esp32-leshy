# Документация ESP32-Leshy

Читать на: [English](README.md) · **Русский**

Документация явно разделена по поколениям прошивки:

- [1.x — активный редизайн](v1/README.ru.md): исследования, требования, продуктовая
  модель, архитектура, решения и план реализации.
- [0.x — архивный proof of concept](archive/v0.x/README.ru.md): выпущенные функции,
  карта меню, предположения о железе и старые процедуры разработки/релиза.

Файлы браузерного установщика (`index.html`, `manifest.json`, изображения и
генерируемые firmware assets) остаются в корне `docs`, потому что GitHub Pages
публикует именно этот каталог.
