ESP32-Leshy

Веб-установщик прошивки — залей на ESP32-DIV прямо из браузера

Web installer — flash ESP32-DIV straight from your browser

Нужен Chrome, Edge или Opera на компьютере (Web Serial). Safari и телефоны не поддерживаются. Needs desktop Chrome, Edge or Opera (Web Serial). Safari and phones are not supported. Открой страницу по https. Open this page over https.

Ставит последний релиз. После первой заливки обновления прилетают по воздуху (Настройки → Обновление).

Flashes the latest release. After the first flash, updates arrive over the air (Settings → Update).

  1. Подключи ESP32-DIV к компьютеру кабелем USB-C (кабель должен быть с данными, не «только зарядка»).
  2. Нажми «Установить» и выбери последовательный порт устройства.
  3. Согласись стереть и прошить. Через минуту устройство загрузится с ESP32-Leshy.
  4. Connect the ESP32-DIV to your computer with a USB-C data cable (not charge-only).
  5. Click Install and pick the device's serial port.
  6. Approve erase & flash. In a minute the board boots ESP32-Leshy.

⚠️ Появилось «Installation failed» / «Failed to initialize»? Плата не вошла в режим прошивки сама — введи её вручную:

  1. Кабель USB-C с данными (не «только зарядка»).
  2. Закрой программы, которые держат порт: монитор порта в IDE (в CLion — вкладка Deploy/Monitor), Arduino, PlatformIO.
  3. Введи плату в режим прошивки: зажми BOOT → нажми RESET → отпусти обе, затем снова «Установить» и выбери порт. (Либо держи BOOT нажатой в момент клика «Установить».)
  4. BOOT и RESET — две маленькие кнопки у модуля ESP32-S3 / рядом с USB; это не кнопки навигации по меню.
  5. Если порт не появляется в списке — поставь драйвер CP2102 (Silicon Labs).

⚠️ Got "Installation failed" / "Failed to initialize"? The board didn't enter flash mode on its own — do it by hand:

  1. Use a USB-C data cable (not charge-only).
  2. Close anything holding the port: an IDE serial monitor (in CLion, the Deploy/Monitor tab), Arduino, PlatformIO.
  3. Put the board into flash mode: hold BOOT → press RESET → release both, then click Install again and pick the port. (Or keep BOOT held while clicking Install.)
  4. BOOT and RESET are the two small buttons by the ESP32-S3 module / next to USB — not the menu-navigation buttons.
  5. If the port never appears, install the CP2102 (Silicon Labs) driver.
