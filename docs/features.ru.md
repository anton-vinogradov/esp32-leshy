# ESP32-Leshy — Возможности

*Читать на: [English](features.md) · **Русский***

Что прошивка умеет сейчас, на реальном железе ESP32-DIV, в меню с кнопками и тачем. Всё здесь — **пассивное / защитное / только своё оборудование**, см. [DISCLAIMER.ru.md](../DISCLAIMER.ru.md).

## Карта меню

```
ESP32-Leshy
├─ Wi-Fi
│  ├─ Скан Wi-Fi        сигнал · канал · шифр · ★своя · скрытые
│  │  └─ ▶ на сети      Подробнее (SSID · BSSID · канал · RSSI · шифр)
│  ├─ Каналы 2.4ГГц     бегущие графики реальной занятости эфира (promiscuous; 1/6/11)
│  ├─ Спектр 2.4ГГц     водопад по всему диапазону 2400-2525 МГц (NRF24, детект несущей)
│  ├─ Частотомер 2.4    на каком канале 2.4-сигнал (hit-rate NRF24 над фоном)
│  └─ Продвинутое
│     ├─ Скрытые сети   раскрытые имена (сохраняются во флеш, удаляются)
│     └─ Детектор атак  пассивная тревога на всплески deauth/disassoc
├─ BLE
│  └─ Скан BLE          устройства рядом + детектор трекеров
├─ Sub-GHz
│  ├─ Спектр            водопад Sub-GHz, «вправо» меняет диапазон (RSSI CC1101)
│  ├─ Частотомер        частота своего пульта (график «подъём над фоном»)
│  └─ Запись-повтор     запись → имя (экранная клавиатура) → сохранить · библиотека
└─ Настройки
   ├─ Wi-Fi подключение настройка с телефона (портал) · статус
   ├─ Обновление        OTA из релизов GitHub
   ├─ Язык              EN / RU
   ├─ Калибровка
   └─ О девайсе
```

Навигация: **▲▼** — выбор, **средняя** — вход/подтверждение, **▶** — опции выделенного, **◀** — назад. Тач тоже работает.

## Wi-Fi

### Скан Wi-Fi
Живой список точек доступа рядом. В строке — имя, мини-**график сигнала точки во времени** (её «след» по последним сканам), **канал** и **RSSI**. Своя сеть помечена **★** (по BSSID — даже если она скрытая). Выбери строку и нажми **▶** — откроются **опции для этой сети** (сейчас *Подробнее*: SSID, BSSID, канал, RSSI, шифр, скрытая/своя). Именно сюда ложатся инструменты для конкретной сети — заходишь из скана, а не из меню.

### Каналы 2.4ГГц
Живые бегущие **area-графики по каждому каналу (1–13)** — «кардиограмма» **реальной занятости эфира**. Устройство слушает в **promiscuous-режиме** и суммирует время в эфире принятых кадров (управление + данные + управляющие), перебирая каналы по одному, — поэтому канал с одной активной точкой обгонит канал, забитый простаивающими. Это **настоящий airtime, а не число точек доступа**. Значение — **нижняя оценка** (считаются только раскодированные кадры, скорость оценивается), поэтому тихий эфир даёт небольшой фон, а реальная загрузка (закачка/стрим) заметно поднимается над ним. Непересекающиеся каналы **1 / 6 / 11** подсвечены. Экран занимает радио целиком — фоновый скан на это время встаёт на паузу.

### Спектр 2.4ГГц
Живой **водопад по всему диапазону 2.4 ГГц** (2400–2525 МГц), который рисует **отдельный радиомодуль NRF24** — своё Wi-Fi у ESP32 при этом свободно. Спектроанализатора у NRF24 нет, но его детектор несущей (RPD) срабатывает на любой сигнал сильнее ~−64 дБм; перебирая все 126 каналов по 1 МГц и раскрашивая каждый по частоте срабатываний, получаем тепловую карту — свежая строка сверху, стекает вниз. Видит **больше, чем Wi-Fi**: Bluetooth, беспроводное видео, дроны, микроволновки — всё, что излучает в диапазоне. Каналы Wi-Fi **1 / 6 / 11** отмечены на оси частот. Нужен установленный модуль NRF24 (слот 2 на ESP32-DIV v2).

### Частотомер 2.4
Наведи на **своё** 2.4-устройство — пульт, метку, аппаратуру дрона — и он покажет, **на каком канале** сигнал. Перебирает все 126 каналов NRF24, меряя **hit-rate** по каждому, и вычитает калиброванный **фон** (постоянный уровень Wi-Fi/Bluetooth), так что остаётся только канал, который *поднимается* при передаче твоего устройства — живой bar-график с отметками Wi-Fi **1 / 6 / 11**, пик читается как `2400 + канал` МГц. Сначала калибровка (пара секунд, не передавай), потом жми кнопку устройства. Только приём.

### Продвинутое → Скрытые сети
Скрытая сеть вещает пустой SSID, но имя всё равно идёт открытым текстом в кадрах **Probe-Response** и **(Re)Association**. Во время скана девайс пассивно достаёт эти имена **только для BSSID, которые скан реально видит скрытыми**, сохраняет во флеш (переживают перезагрузку) и показывает здесь с удалением. Пассивно — имя всплывает только когда к сети есть реальный трафик (клиент запрашивает её или подключается).

### Продвинутое → Детектор атак
Пассивная тревога только на приём: следит за эфиром (перебирая каналы) и ловит всплески кадров **deauthentication / disassociation** — почерк deauth-атаки на сеть рядом. Показывает счётчик за окно, всего, текущий канал и MAC источника. Только защита.

## BLE

### Скан BLE
Список Bluetooth-LE устройств рядом, **отсортированный по сигналу (ближние сверху)**, метит известные **трекеры** (Apple Find My / Tile / Samsung SmartTag).

## Sub-GHz

### Спектр
Живой водопад Sub-GHz-диапазона на **CC1101** — он даёт настоящий RSSI по каждой частоте (реальная сила сигнала, а не только «есть/нет»). **«Вправо» переключает окно показа**: весь диапазон 300–928 МГц, затем прицельные технические полосы — **315** (авто-брелоки/гаражные пульты/датчики давления), **433** (сигналки, пульты, датчики), **868** (EU LoRa / Meshtastic), **915** (US LoRa / Meshtastic) и узкий **433 подробно**. Отрисовка без мерцания, как на экране 2.4 ГГц, с легендой «тихо→занято». Только приём. Нужен установленный модуль CC1101.

### Частотомер
Найди частоту **своего** sub-GHz пульта или датчика. Поднеси к антенне и жми кнопку; CC1101 перебирает свои настраиваемые окна (300–348 / 387–464 / 779–928 МГц) и — после калибровки фона в два прохода, которая запоминает шумовой пол и собственные кварцевые «птички» чипа, — показывает частоту того, что *поднимается* над этим фоном, с уточнением до ~50 кГц и подсказкой диапазона вроде `868 ISM`. Это живой **график «подъём над фоном» по частоте** (с компенсацией дрейфа, кварцевые гармоники отсеиваются), поэтому реальное нажатие — чистый пик, а спуры остаются в фоне. **OK** включает аттенюацию −18 дБ ближнего поля, чтобы метка вплотную не перегружала вход. Только приём.

### Запись-повтор
Запись и воспроизведение **своих** OOK/FSK-устройств — пультов, датчиков — в 300–928 МГц. **Запись** снимает последовательность вкл/выкл (огибающая RSSI для OOK, демодулятор GDO0 для FSK), затем задаёшь имя на **экранной клавиатуре** и сохраняешь. **Воспроизведение** листает сохранённую библиотеку (переживает перезагрузку — хранится в файловой системе флеша), проигрывает запись или удаляет. **Настройки** (портал с телефона) задают время прослушивания, точную частоту, порог захвата, число повторов, модуляцию и полярность. Только своё железо — без захвата роллинг-кодов и без воспроизведения чужих сигналов.

## Настройки

### Wi-Fi подключение
Вход в **свою** сеть без клавиатуры: девайс поднимает точку `ESP32-Leshy-setup` с captive-порталом; SSID и пароль вводишь **с телефона**. Данные сохраняются, показывается статус (SSID / IP). Через это же соединение девайс выходит в сеть для обновлений.

### Обновление (OTA)
Обновление прошивки прямо из **релизов GitHub**: проверяет последний релиз, и если новее — качает прошивку по TLS в свободный OTA-слот, сверяет **SHA-256** и перезагружается в неё. Сначала синхронизируется время по SNTP (TLS требует корректных часов), цепочка сертификатов проверяется по встроенному бандлу Mozilla, а анти-откат загрузчика сам вернёт старую прошивку, если новая не загрузится. Девайс **автоматически проверяет обновления при подключении к Wi-Fi** и показывает янтарную стрелку в шапке, когда обновление доступно.

### Язык / Калибровка / О девайсе
Язык интерфейса (EN / RU), перекалибровка тача и информация об устройстве (железо, версия прошивки, автор).
