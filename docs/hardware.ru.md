# Железо

*Читать на: [English](hardware.md) · **Русский***

Целевая платформа ESP32-Leshy — **ESP32-DIV v2** от [CiferTech](https://github.com/cifertech/ESP32-DIV). Железо мы не делаем и не продаём — плату берите там (или собирайте совместимую DIY-версию).

## Модули

| Компонент | Шина | Роль |
|-----------|------|------|
| ESP32-S3 | — | главный MCU, встроенные Wi-Fi + BLE |
| ILI9341 2.8" TFT | SPI | дисплей |
| XPT2046 | SPI | резистивный тач |
| 3× NRF24L01(+) | SPI | 2.4 ГГц скан / спектр / TX |
| CC1101 | SPI | Sub-GHz (300–928 МГц) приём/повтор |
| PN532 | SPI | RFID / NFC (13.56 МГц) |
| NEO-6M GPS | UART | wardriving, время |
| ИК TX/RX | GPIO | пульты |
| microSD | SPI | логи, профили, PCAP |
| IP5306 (I2C-вариант) | I²C | батарея / заряд |
| PCF8574 | I²C | расширитель кнопок (v2.x) |
| WS2812 ×4 | GPIO1 | статус-светодиоды |
| CP2102 | USB | прошивка / serial |

## Аппаратные грабли

- **Общая SPI-шина** тача, радио и SD — источник бага №1 (тач залипает после RF). Leshy выносит тач на вторую SPI-шину. У ESP32-S3 два аппаратных SPI — используйте оба.
- **Индикатор батареи**: на плате вариант **IP5306-I2C**, а ADC-делитель может быть не разведён — читать заряд по I²C-регистрам, не по напряжению.
- **GPIO1 = UART0 TX** ещё и на NeoPixel — лог через UART0 конфликтует; логировать через USB-CDC или отключать.
- **GPIO14** на части ревизий делят ИК-передатчик и NRF24 — планируйте пины до включения обоих.
- **NRF24 PA/LNA** тянут импульсный ток — конденсатор 10–100 мкФ по 3.3 В, иначе браунаут ESP32.

> Точную распиновку зафиксируем после проверки на живой плате. Если ваша сборка отличается — пины будут в одном board-config заголовке.
