# Разработка ESP32-Leshy

Всё для сборки, заливки, запуска и релиза прошивки. English — [DEVELOPING.md](DEVELOPING.md).

Железо: **ESP32-DIV v2** (ESP32-S3 + USB-serial CP2102). Тулчейн: **PlatformIO**
(`pio` лежит в `~/.platformio/penv/bin/pio`, на `PATH` его нет).

---

## Одной кнопкой в CLion

В репозитории лежат общие конфигурации запуска (`.idea/runConfigurations/*.xml`).
После **VCS → Update Project** они появятся в выпадашке справа сверху — выбери и жми
зелёный ▶ (или `⌘R`). Каждая запускает маленький скрипт из `tools/`, который сам
проставляет `PATH` и рабочую папку.

| Кнопка | Скрипт | Что делает |
|--------|--------|------------|
| **Build** | `tools/build.sh` | Только сборка (`pio run`). |
| **Deploy to device** | `tools/deploy.sh` | Сборка + заливка по USB. **Только заливка** — порт освобождается сразу после прошивки. |
| **Monitor (serial)** | `tools/monitor.sh` | Монитор порта на 115200. Держит порт, пока не остановишь (красный ■). |
| **Release (tag + CI)** | `tools/release.sh` | Ставит тег на `HEAD` и пушит → CI собирает и публикует (см. [Релиз](#релиз)). |

Один раз — для автодополнения / навигации по коду (на кнопки не влияет):

```bash
~/.platformio/penv/bin/pio project init --ide clion
```

## Из командной строки

Скрипты работают и прямо из терминала, как и «сырые» команды:

```bash
tools/build.sh        # или: pio run
tools/deploy.sh       # или: pio run -t upload
tools/monitor.sh      # или: pio device monitor -b 115200
```

## Ежедневный цикл

1. Правишь код.
2. **Deploy to device** (`⌘R`) — залил, порт снова свободен.
3. **Monitor (serial)** — когда нужны логи.

Порт держит только одна программа за раз. **Останавливай монитор (■) перед повторной
заливкой или веб-установщиком** — иначе следующее подключение упадёт с ошибкой
занятого порта / «Failed to initialize».

## Serial-команды

Печатай в мониторе, чтобы управлять устройством по USB:

- **Навигация:** `u` `d` `l` `r` (вверх/вниз/влево/вправо), `o` (OK/выбор), `menu` (домой).
- **Wi-Fi / BLE:** `s` или `scan`, `ble`, `hidden`, `conn`, `deauth`.
- **Спектр / эфир:** `chan`, `air`, `nrf` (NRF24 2.4 ГГц), `cc` (CC1101 Sub-GHz).
- **Обновление / правовое:** `ota`, `legal`.
- **Настройки:** `leds`, `ledbr` (яркость LED), `bl` (подсветка экрана).
- **Диагностика / dev:** `stat` (куча/статус), `nrfdiag`, `otafail`, `legalreset`.

## Прошивка чистой платы (веб-установщик)

Для платы без тулчейна — установщик в браузере:
**https://anton-vinogradov.github.io/esp32-leshy/** (Chrome / Edge / Opera, по https).

ESP32-DIV прошивается через CP2102, а его авто-сброс из Web Serial ненадёжен — поэтому
в download-режим надо входить руками. Кнопки на плате:
**BOOT — сверху слева, RESET — сверху справа** (третья, снизу справа, — питание).

1. **Зажми BOOT и держи, не отпуская.**
2. Нажми **«Установить»**, выбери порт `cu.usbserial-0001`.
3. **Отпусти BOOT только когда пошла полоса заливки.**

Если всё равно не подключается — добавь тап по RESET при зажатом BOOT (BOOT → RESET →
отпустить RESET, BOOT держать), затем Install. Для своей платы всё это не нужно —
**Deploy to device** сбрасывает и заливает сам.

## Релиз

`tools/release.sh` (или кнопка **Release**) ставит тег на `HEAD` и пушит его:

```bash
tools/release.sh          # авто-бамп патча: v0.4.2 -> v0.4.3
tools/release.sh v0.5.0   # явная версия для minor/major
```

Дальше CI (`.github/workflows/release.yml`) вшивает версию в `src/core/version.h`,
собирает и публикует релиз на GitHub с двумя файлами:

- `firmware.bin` — образ для OTA (устройства берут его через **Настройки → Обновление**).
- `firmware.factory.bin` — полный образ для веб-установщика.

Воркфлоу Pages обновляет сайт установщика свежим factory-образом.

## Железо кратко

- **MCU:** ESP32-S3. **USB-serial:** CP2102 → `/dev/cu.usbserial-0001`.
- **Радио (FSPI, SCK 12 / MISO 13 / MOSI 11):** 3× NRF24 (2.4 ГГц) + CC1101 (Sub-GHz).
- **Дисплей:** ILI9341 на HSPI. **Подсветка:** GPIO7 (PWM). **Статус-LED:** GPIO1, 4× WS2812.

Детали — в `platformio.ini` и исходниках под `src/`.
