# ESP32-Leshy documentation

Read this in: **English** · [Русский](README.ru.md)

Documentation is explicitly split by firmware generation:

- [1.x — active redesign](v1/README.md): discovery, requirements, product model,
  architecture, decisions, and implementation roadmap.
- [0.x — archived proof of concept](archive/v0.x/README.md): released feature set,
  menu map, hardware assumptions, and legacy development/release procedures.

The files used by the browser installer (`index.html`, `manifest.json`, images, and
generated firmware assets) remain at the documentation root because GitHub Pages
publishes this directory.
