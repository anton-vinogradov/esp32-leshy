## Статус разработки и роадмап

> **Сейчас: S6 — Продуктовые отличия: Targets, compare и companion**
>
> Закрыто этапов: 5 из 9.

Этот срез главной страницы генерируется из документации-точки-истины 1.x; CI отклоняет рассинхрон.

- **Текущая фаза:** `S6.5 — local USB/Web companion над общими Actions и schemas`.
- **Проверенный checkpoint:** exact `0.195.0-companion-web-gzip-index` на firmware source `52570c587b34f73a9d35628b554cbac5b76063f8` физически принят для **offline USB-only** companion boundary в `E-BUILD-152`/`E-AUTO-124`/`E-HIL-182`/`E-COMPANION-006`. Без прошивки и network tools явный порт оригинального DIV экспортирует 2 Session, 16 Target со всеми 16 полными detail projections и 7 comparison items в canonical snapshot `leshy.companion.offline.v1` размером 11 521 byte. Два run дают одинаковые snapshot ID и file SHA-256; локальный case-folded поиск охватывает name, notes, tags и normalized identities. Exact CID/generation 161/59 сохраняются read-only с zero physical writes, radio TX, Cardputer opens, input drops и leaked leases. Retained evidence содержит только hashes/counts, без private payload/queries, и фиксирует, что активный Wi-Fi Mac не трогался.
- **Следующий gate:** исправить и USB-only проверить дефект lifecycle памяти устройства после Web: после прежнего lifecycle Local Web повторное открытие Targets может завершить read-only mount с `ESP_ERR_NO_MEM` до reset DIV. Воспроизведение и ремонт могут запускать/останавливать собственную AP DIV через serial diagnostics, но не будут подключать, перенастраивать или отключать ни один network interface Mac. Physical HTTP parity остаётся отложенной до отдельного idle adapter/external client. Physical gate S5 остаётся отложенным до приезда replacement DIV и прохождения его read-only profile.

## Что строит 1.x

Leshy становится полевым инструментом с законченным сценарием:

> обнаружить → идентифицировать → локализовать → записать → сравнить → безопасно
> воспроизвести на своём стенде → сохранить и экспортировать результат.

Продукт строится вокруг Обзора, Целей, Захвата, Лаборатории, Библиотеки и Устройства,
а не постоянно растущего списка разрозненных радиоэкранов. Wi-Fi, BLE, NRF24, CC1101,
IR, NFC, GPS и хранилище становятся общими возможностями этих сценариев.

Документация определяет scope и gates 1.x. Текущее состояние кода, прототипов и
проверок фиксируется только в [STATUS](docs/v1/STATUS.ru.md). Роадмап на главной

```bash

tools/test.sh
tools/build.sh
```

## Ответственное использование

Используйте Leshy только со своим оборудованием или там, где есть явное письменное
разрешение. Наблюдение — режим по умолчанию. Передача и replay находятся в отдельной
Лаборатории с видимым состоянием, ограниченным временем и мгновенной остановкой.
